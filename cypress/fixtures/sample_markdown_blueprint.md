# Input Parameters

The Plugin Showcase was run with the following parameters.
You can check if your input was received in the correct manner.
Be aware that if you did not specify a value, some of the optional parameters may use defaults.

```json
{
    "bool_showcase": true,
    "int_showcase": 3,
    "float_showcase": 2.1,
    "string_showcase": "John Doe",
    "date_showcase": "2020-01-01",
    "select_showcase": "Option 2",
    "select_multi_showcase": [
        "Option 2"
    ],
    "mapping_showcase": {
        "good": "John Doe",
        "mediocre": 2.1,
        "bad": "Option 2"
    }
}
```
